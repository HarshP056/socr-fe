Special Features
Fallback Same target field with higher priority number. Tried only if lower priority returns empty.
e.g. cac:Item/cbc:Description (pri 1) → cac:Item/cbc:Name (pri 2)
Value Regex Extracts group 1 from raw text.
e.g. PO\s*(\d+) on "PO 4500012345" → "4500012345"
Date Format Java date pattern for DATE type fields. Default: yyyy-MM-dd
